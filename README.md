# Salidas G7

App web (PWA) que convierte el mensaje de WhatsApp en imagen, Excel y PDF.

## Publicar y usar en iPhone
1. Creá un repositorio nuevo en GitHub y subí todo el contenido de esta carpeta (incluida la carpeta `.github`).
2. En el repositorio: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. En la pestaña **Actions** esperá a que termine «Build y publicar en GitHub Pages». Si no arrancó, ejecutalo con *Run workflow*.
4. Abrí en **Safari** la dirección `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`.
5. Tocá **Compartir → Añadir a pantalla de inicio**. Se abre como una app más.

Cada vez que subas cambios a `main`, la app se vuelve a publicar sola.
